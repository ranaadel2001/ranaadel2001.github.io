## Before publishing
- Check that your LinkedIn URL is correct.
- Review every project description and remove anything you are not allowed to share publicly.
- The email address is included as a contact link. Remove it if you prefer not to publish it.
- All project summaries are brief public-facing summaries; avoid adding confidential client details.

## Publish with GitHub Pages
1. Create a public repository named `ranaadel2001.github.io` (or use your own exact GitHub username if it differs).
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Once deployment finishes, visit `https://ranaadel2001.github.io`.

This site is separate from the GitHub profile page itself.
